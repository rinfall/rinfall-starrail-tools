# Rinfall StarRail Tools (RST)

一个面向《崩坏：星穹铁道》的轻量、高效日常任务自动化工具。

---

## 🌟 特性

- **极简纯粹**：纯 Python 3.12+ 架构，无臃肿的跨语言通信与多进程中转。
- **高确定性视觉**：相对比例坐标 + 模板掩码匹配 + 图像二值化预处理，彻底解决 OCR 认错与动态背景干扰问题。
- **状态机自愈**：基于页面指纹的状态感知，遇到月卡、签到、活动公告等弹窗自动按 ESC 平滑回退，拒绝粗暴杀进程。
- **完整自动化链路**：支持从游戏启动、登录、大世界导航、副本传送、托管自带自动战斗到自动结算循环的全流程。

## 🚀 快速开始

### 1. 环境准备
确保已安装 Python 3.12 及以上版本：
```bash
python --version
```

安装项目依赖：
```bash
pip install -e .
```

### 2. 配置修改
复制并编辑 `config.yaml`，填入你的游戏路径、目标副本与刷取偏好。

### 3. 运行
在终端中执行：
```bash
python main.py
```
