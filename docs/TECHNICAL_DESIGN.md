# Rinfall StarRail Tools 技术方案设计书

## 1. 方案背景与目标

### 1.1 项目定位
**Rinfall StarRail Tools (RST)** 是一款轻量、极速、抗版本更新的游戏日常自动化核心引擎。第一阶段专注于打造运行稳定、资源占用低、识别确定性高的纯 Python 3.12+ 内核，通过命令行（CLI）和配置文件驱动运行，无需前端 GUI 依赖。

### 1.2 核心设计原则
1. **纯净单进程架构**：纯 Python 实现，避免跨语言中转、进程间管道（Pipe）通信与脆弱的超时锁。
2. **高确定性视觉**：
   - 交互三级分流：固定比例坐标盲点 > 掩码轮廓模板匹配 > 局部预处理 OCR。
   - 杜绝全屏模糊 OCR，所有文字识别均经过 ROI 局部裁剪与图像二值化（黑白化）预处理。
3. **低维护成本**：减少全量大图依赖，关卡导航以文字标题为主，关键按钮以掩码轮廓为主。
4. **状态机容错自愈**：基于页面指纹的状态感知，突发弹窗通过 ESC / 盲点自愈回退，避免强行杀进程。

## 3. 核心视觉与交互设计

### 3.1 相对比例坐标（0.0 ~ 1.0）
所有屏幕点位均以 `1920 × 1080`（16:9）标准为基础换算为浮点比例：
- 屏幕实际像素 $X = ClientLeft + ClientWidth \times rx$
- 屏幕实际像素 $Y = ClientTop + ClientHeight \times ry$
无论游戏处于任意分辨率，业务代码无需调整。

### 3.2 图像预处理流水线（OCR 优化）
1. **ROI 裁剪**：体力区域仅裁剪约 `250 × 40` 像素；
2. **二值化处理**：通过高亮色彩提取与阈值化，将半透明星空背景抹为纯黑（0），文字提取为纯白（255）；
3. **纯识别模式**：跳过目标检测网络（`use_det=False`），单次识别耗时控制在 15ms 内，识别率 > 99.9%。

### 3.3 掩码匹配（Mask Matching）
对于易受背景动态光效影响的按钮，采用线框模板并配套透明通道掩码：
`cv2.matchTemplate(image, template, cv2.TM_CCORR_NORMED, mask=mask)`，仅匹配按钮本体线条。

## 4. 全流程业务步骤规划

1. **步骤 1：脚本启动与配置装载**：解析 `config.yaml`。
2. **步骤 2：游戏实例接入**：
   - 若未启动：拉起 `StarRail.exe` 并等待句柄；
   - 若已启动：激活已有窗口。
3. **步骤 3：登录鉴权与状态对齐**：
   - 快速免密：直接点击“开始游戏”；
   - 账密过期：剪贴板填充账号与密码，勾选协议登录；
   - 滑块拼图：触发提示，等待人工协助处理；
   - 弹窗清理：清理公告、月卡等弹窗，抵达大世界。
4. **步骤 4：快捷键读体力**：按 `F4` 唤起生存索引，二值化 OCR 识别体力。
5. **步骤 5：副本导航与交互**：文字匹配目标副本，点击传送，落地按 `F` 进本。
6. **步骤 6：战斗托管与监控**：按 `V` 激活内置自动战斗，低频休眠监听结算画面。
7. **步骤 7：连刷循环与收尾**：体力充足点“再次挑战”，体力耗尽点“退出战斗”，打印报告并优雅退出。
